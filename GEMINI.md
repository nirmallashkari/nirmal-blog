# Daily Publishing & Content Rules (LOCKED)

These rules are always active for all posts, logs, outreach messages, bios, and public content created from this workspace.

## 1. Never Use Em-Dash (`—`)
- **STRICTLY FORBIDDEN:** Never use the `—` (em-dash) character (or `–` en-dash) anywhere in posts, captions, DMs, comments, or logs.
- Use simple periods `.`, commas `,`, line breaks, or a plain hyphen `-` instead.

## 2. Human Imperfect Grammar (Avoid Perfect AI Grammar)
- Do **not** write overly polished, textbook-perfect, symmetrical grammar.
- Write like a real founder typing quickly on a laptop or phone: natural flow, occasional casual fragments, minor human imperfections in phrasing/punctuation, and zero robotic symmetry.
- Avoid corporate or AI buzzwords (no "leverage", "elevate", "seamless", "game-changer", "delve", "unlock", "testament", "empower").

## 3. Language & Voice
- **Pure English only** for all public content (GitHub, LinkedIn, X, Instagram, outreach DMs). Never use Hinglish or Hindi in public posts or messages.
- Always write in **first person** using **"I"**, **"we"**, or **"our agency"** so it reads directly from Nirmal / First Look Sites.
- Never put raw markdown `**bold**` asterisks inside LinkedIn, X, or Instagram text.

## 4. Platform Publishing Standards
- **GitHub (`nirmallashkari/nirmal-blog`):** Daily build log pushed to `main`. Exclude all private client data, NDA work, API keys, and raw lead sheets.
- **LinkedIn (`nirmallashkari90`):** Publish via Chrome port `9222`.
- **X (`@NirmalLashkari1`):** Keep posts concise (under 280 chars) and publish via Chrome port `9222`.
- **Instagram (`@nirmal.lashkari`):** Always render cards at **`1080x1350` (`4:5` safe-zone)** with wide side margins so zero text crops in Instagram's `3:4` profile grid, and select `4:5` / `Original` crop during upload.
